## Overview

This project focuses on developing a personalized home assistant robot using the TIAGo robotic platform, leveraging cutting-edge technologies like OpenAI Whisper for speech recognition, ChatGPT 4o model for reasoning and decision-making, and ElevenLabs for generating natural speech responses. The primary objective is to create a system that enables intuitive natural language interaction, adaptive task execution, and efficient collaboration with users in dynamic home environments. The proposed framework emphasizes modularity, scalability, and integration with state-of-the-art algorithms, enabling the TIAGo robot to perform tasks such as pick-and-place operations or personalized conversational interactions. For more insights about our methodology, check the report linked above.
